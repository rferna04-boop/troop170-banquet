# Scouts BSA Troop 170 - 2026 Annual Banquet & Scout Presentations

Official microsite and event portal for the **Scouts BSA Troop 170 Annual Banquet & Scout Presentations 2026**.

## 🌲 Overview

This responsive, self-contained web application celebrates the accomplishments of Troop 170 Scouts over the 2025–2026 Scouting year, spotlighting:
- **Eagle Scout Class of 2026** recognition & service projects
- **Order of Events & Ceremony Schedule**
- **Catered Banquet Dinner Menu** with dietary options
- **Interactive Ticket & RSVP Calculator** with instant confirmation and `.ics` calendar generation
- **Silent Auction & Troop Fundraiser Showcase** with proxy bidding simulation
- **Year-in-Review Photo Gallery** with category filtering
- **Interactive Digital Guestbook / Tribute Wall**
- **Venue Directions, Parking Information & FAQs**
- **Printable Program Format** (`@media print` optimized for physical event programs)

## 🚀 Quick Start / Viewing Locally

Simply open `index.html` in any modern web browser:
```bash
open index.html
```

Or serve with any static HTTP server:
```bash
npx serve .
# or
python3 -m http.server 8080
```

## 🌐 Deploying to GitHub Pages

1. Push this repository to GitHub.
2. In your repository settings, navigate to **Settings > Pages**.
3. Under **Build and deployment > Branch**, select `main` (root) and click **Save**.
4. Your site will be published at `https://<username>.github.io/<repo-name>/`.
